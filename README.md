# 🥄 Ladle Fall - QR & Barcode Generator

A simple, elegant web application to generate QR codes and barcodes instantly.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## ✨ Features

- 📱 **QR Code Generation** - Generate QR codes from any text or URL
- 📊 **Barcode Generation** - Create CODE128 barcodes supporting alphanumeric text
- 💾 **Download** - Save generated codes as PNG images
- 🎨 **Modern UI** - Beautiful gradient design with smooth animations
- 📱 **Responsive** - Works perfectly on mobile and desktop
- ⚡ **Real-time** - Generates codes as you type

## 🚀 Live Demo

Visit the live demo: [https://yourusername.github.io/ladlefall-qr-generator](https://yourusername.github.io/ladlefall-qr-generator)

## 🛠️ Usage

Simply open `index.html` in your browser or host it on any web server.

1. Enter text or numbers in the input field
2. QR code and barcode are generated automatically
3. Click download buttons to save the images

## 🎯 Technologies Used

- Pure HTML5/CSS3/JavaScript
- [QRCode.js](https://davidshimjs.github.io/qrcodejs/) - QR code generation
- [JsBarcode](https://github.com/lindell/JsBarcode) - Barcode generation

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ladlefall-qr-generator.git

# Navigate to the directory
cd ladlefall-qr-generator

# Open in browser
open index.html
```

## 🌐 Deployment

### GitHub Pages
1. Go to repository Settings
2. Navigate to Pages section
3. Select branch `main` and Save
4. Your site will be live at `https://yourusername.github.io/ladlefall-qr-generator`

### Custom Domain
Add a CNAME record in your DNS settings pointing to your GitHub Pages URL.
